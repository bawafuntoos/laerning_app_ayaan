# LearnQuest Mumbai

A cheerful, browser-based practice app for an ICSE Class 3 learner in Mumbai. It includes Maths, Science, Hindi, Marathi, and Social Studies missions, with instant feedback and stars.

## Run it

```powershell
cd C:\Projects\Mumbai_Learning_Adventure
python -m pip install -r requirements.txt
streamlit run app.py
```

Progress is deliberately stored only for the current browser session.

## Share it on a phone (free public link)

1. Create an empty repository on GitHub, for example `mumbai-learning-adventure`.
2. Upload the contents of this folder to that repository (the `app.py` file must be at the top level).
3. Go to [Streamlit Community Cloud](https://share.streamlit.io/), sign in with GitHub, and select **Create app**.
4. Choose the repository, branch, and `app.py`, then click **Deploy**.
5. Copy the URL that Streamlit gives you and open it on any phone.

No passwords or private data are needed by this app. It uses browser-session progress, so each new browser session starts fresh.
